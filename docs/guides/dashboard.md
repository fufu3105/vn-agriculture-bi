# Run the Dashboard

[Project overview](../README.md) | [Environment setup](environment_setup.md#python-environment)

Install the Python dependencies first and run the command from the repository root. Java is not required for this CSV-based dashboard.

Start the Streamlit application:

```powershell
.\.venv\Scripts\python.exe -m streamlit run dashboard/app.py
```

Open the local URL printed in the terminal, normally [http://localhost:8501](http://localhost:8501), and keep the terminal running. Press `Ctrl+C` to stop the application.
